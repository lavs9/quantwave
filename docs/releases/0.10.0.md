# Release 0.10.0 — Tier 1 Smart Money Concepts, Time & Sessions, Volume Profile, and Core Correctness

**Date:** 2026-11-11  
**Install:** `pip install quantwave` or `pip install "quantwave[polars]"`

---

## Headline

QuantWave 0.10.0 expands the library's technical analysis suite with Tier 1 Smart Money Concepts (SMC/ICT), modern Market Structure tools, intraday Session Levels, and Auction Theory Volume Profile. All implementations are written in native Rust with guaranteed bit-identical streaming and Polars batch parity.

Alongside the new indicators, 0.10.0 resolves six dogfooding findings from production 9-EMA and Trend Target Ribbon backtests (GH-55 through GH-60): comprehensive parameter and dimension validation, self-healing NaN recovery for moving windows, Wilder vs EMA ATR smoothing and initial direction configuration for SuperTrend (recovering missed IPO breakout setups), cross-sectional universe ranking, and seamless argument order flexibility.

---

## What's New

### 1. Tier 1 Smart Money Concepts & Market Structure
- **Order Blocks (`order_blocks` / `OrderBlock`)**: Detects high-probability institutional mitigation zones formed prior to explosive market displacement.
- **Fair Value Gaps (`fair_value_gaps` / `FairValueGap`)**: Identifies 3-bar untraded liquidity imbalances (bullish and bearish FVGs) with progressive fill and mitigation tracking.
- **Liquidity Sweeps (`liquidity_sweeps` / `LiquiditySweep`)**: Tracks pivot wick pierce-and-reclaim events that sweep resting buy-side or sell-side liquidity.
- **Market Structure State Machine (`bos_choch` / `MarketStructure`)**: Monitors swing high/low pivots to classify Break of Structure (BOS) trend continuations and Change of Character (CHoCH) reversals.

### 2. Time & Sessions Suite
- **Session VWAP (`session_vwap` / `SessionVwap`)**: Intraday session Volume Weighted Average Price with dynamic standard deviation bands (±1σ, ±2σ, ±3σ) anchored to market trading sessions.
- **Opening Range Breakout (`orb` / `OpeningRangeBreakout`)**: Toby Crabel-style opening range high/low boundary tracking with directional breakout/breakdown signals.

### 3. Levels & Auction Theory
- **Volume Profile (`volume_profile` / `VolumeProfile`)**: Rolling and session-anchored Volume Profile yielding Point of Control (POC), Value Area High (VAH), and Value Area Low (VAL).

### 4. Cross-Sectional Universe Ranking
- Added `expr.ta.cross_sectional_rank(group_by=...)` on Polars expressions and top-level `quantwave.cross_sectional_rank(data, ...)` supporting ascending/descending ordering and percentile scaling across symbol universes.

### 5. SuperTrend Startup & Seeding (GH-59)
- **Initial Direction Option**: Added `initial_direction="down" | "up" | "from_close"`. Allows IPO-base setups to start in a downtrend (`-1`) so the initial breakout above resistance is cleanly captured, restoring 17% of previously lost setups in early listing windows.
- **Wilder ATR Smoothing**: Configurable `smoothing="wilder" | "ema"`. Wilder smoothing seeds ATR with an SMA after `period` bars and emits `NaN` during warmup.

### 6. Moving Average Warmup Policies (GH-55)
- Support for `WarmupPolicy::Partial` and `WarmupPolicy::Nan` across `SMA`, `EMA`, and `ALMA`. Plain API and Polars plugins allow choosing between partial-window accumulations or `NaN`s during initial warmup bars.

## Core Correctness & Dogfood Fixes

- **Parity on NaN Inputs (GH-60)**: Polars `.ta` plugins and plain streaming indicators share bit-for-bit identical NaN propagation and recovery semantics.
- **Polars ATR Column Output Naming (GH-60)**: Fixed output naming for `.ta.atr()`, `.ta.natr()`, and `.ta.trange()` so columns are named after the receiver series (`c` or `close`) instead of `h` (`high`).
- **Flexible Argument Order (GH-60)**: Plain Python wrappers accept both `(period, series...)` and `(series..., period)`.
- **Parameter Validation (GH-57)**: Enforces `period >= 1` across all indicator macros, raising `ValueError` on invalid or negative periods, and validates matching array lengths on multi-input indicators.
- **Self-Healing NaN Recovery (GH-56)**: `EMA`, `TaBETA`, and rolling aggregators recover their states once a transient `NaN` ages out of the window.
- **Import Warnings (GH-58)**: Suppressed noisy `UserWarning`s when importing `quantwave` without Polars or NumPy installed.
