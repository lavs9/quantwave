## Release 0.10.1: Plain vs. Polars ATR Parity, Moving Average Warmup in Polars, and Rule S14 Gap Reset

### Fixed
- **ATR Plain vs. Polars Parity (#61)**:
  - Both `quantwave.atr` and `pl.col().ta.atr` now default to Wilder's RMA (`alpha = 1/period`, SMA seed after `period` bars with NaN warmup), eliminating the previous divergence where plain ATR used EMA (2.22) and Polars ATR used Wilder (2.14).
  - Both plain and Polars APIs and `quantwave.Atr` streaming class now support `smoothing="wilder"` (default) and `smoothing="ema"`.
- **Moving Average Warmup Options in Polars `.ta` (#61)**:
  - Added `warmup="partial" | "nan"` to `pl.col().ta.sma`, `pl.col().ta.ema`, and `pl.col().ta.alma`. Under `warmup="nan"`, initial bars emit NaN until the full period window is satisfied.
  - Added `warmup` argument to plain `quantwave.alma` and `quantwave.Alma`.
- **Top-Level `rocp` Function and Streaming Class (#61)**:
  - Added top-level `quantwave.rocp` and `quantwave.Rocp` streaming class returning fractional ratio returns `(p - p_prev) / p_prev`.
  - Added explicit documentation distinguishing `roc` (percentage points, 100×) from `rocp` (decimal fraction, 1×).

### Added
- **Trading Halt & Data Hole Recovery Helper (Rule S14, #61)**:
  - Added `quantwave.apply_with_gap_reset(indicator_factory, *series_args, max_gap=5)` to restart stateful indicators (EMA, SuperTrend, ATR, etc.) after gaps of more than `max_gap` consecutive missing/NaN bars, preventing momentum leakage across trading halts.
